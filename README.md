## House Price Prediction:-

This project focuses on analyzing housing data and building a machine learning model to predict house prices (SalePrice). The insights gained will also be used to suggest effective house-shopping strategies for customers based on their specific requirements.

## Project Objectives:-
1.Complete a comprehensive data analysis report on the provided housing dataset.
2.Build a robust machine learning model to predict SalePrice and explain how various features relate to the final price. 
3.Provide actionable recommendations for customers shopping for a house based on area, price, and other requirements.

## Dataset Overview:-
1.The dataset is loaded from a file named data.csv.
2.It contains 1,460 observations and 81 features.
3.Several features have a significant amount of missing data that will require handling, including PoolQC (99.5% missing), MiscFeature (96.3% missing), Alley (93.8% missing), and Fence (80.8% missing).
